## 계산법

1. **전문의 수.** 진료과목정보 파일(CP949)에서 진료과목코드 11(소아청소년과) 행의 `과목별 전문의수`를 `암호화요양기호`별로 더했습니다. 이를 병원정보 파일(CP949)과 `암호화요양기호`로 연결했습니다.
2. **시군구.** 병원 `주소`의 앞 두 단어(시도 + 시군구)를 썼습니다. `광주광역시`·`전라남도`로 시작하는 주소는 `전남광주통합특별시`로 바꿨고, 세종특별자치시는 하나의 지역으로 묶었습니다.
3. **어린이 수.** KOSIS 파일은 확장자가 .xls지만 실제로는 XML(SpreadsheetML)이라 XML로 읽었습니다. `데이터` 시트에서 `총인구수[명]`의 `0 - 4세`, `5 - 9세`, `10 - 14세`의 `2026.09 월` 값을 더했습니다. 시도 열이 없어 시도 이름 행 아래 행들을 그 시도의 시군구로 보았고, 전국·시도 합계 행과 `출장소` 행(경기 북부출장소, 강원 동해출장소)은 뺐습니다. 세종은 같은 블록이 두 번 있어 한 번만 셌습니다.
4. **비율과 순위.** `전문의 수 ÷ 0~14세 인구 × 10,000`. 순위는 반올림하기 전 값으로 높은 순서로 매겼고, 같은 값은 공동 순위(가장 높은 순위 번호)로 처리했습니다. 화면에는 소수 둘째 자리까지 표시합니다.

## 한계

- 전문의는 **일하는 곳**, 어린이는 **사는 곳** 기준입니다. 대학병원이 모인 도심 구는 값이 크게 나오고, 이웃 지역 어린이를 진료하는 몫은 반영되지 않습니다. 접근성 지표가 아니라 ‘인력이 어디에 있는가’에 가까운 지표입니다.
- 어린이가 적은 지역은 전문의 한두 명으로 값과 순위가 크게 흔들립니다.
- 소아청소년과는 18세까지 진료하지만 분모는 0~14세입니다.
- `과목별 전문의수`는 기관이 신고한 진료과목 기준입니다. 소아청소년과를 진료과목으로 올리지 않은 기관의 전문의는 빠지며, 상근·비상근 여부나 실제 진료 시간은 알 수 없습니다.
- 0명은 소아청소년과 진료과목으로 신고된 전문의가 없다는 뜻이지, 소아 진료가 전혀 없다는 뜻은 아닙니다.
- 일반구가 있는 시(예: 수원시, 포항시)는 시 단위로 집계했습니다(병원 주소 앞 두 단어와 KOSIS 표의 단위가 같음).
